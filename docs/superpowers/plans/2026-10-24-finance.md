# Свод Implementation Plan

> Execute inline using superpowers:executing-plans. User authorized implementation after plan; no commits or new branches requested.

**Goal:** Self-hosted password-protected multi-currency account balance tracker.

**Architecture:** Node HTTP API, SQLite persistence, native JS frontend. Daily cached FX snapshots and dated balance snapshots.

**Tech Stack:** Node.js >=24, SQLite, HTML/CSS/JavaScript, Docker ARM64.

**Spec:** docs/superpowers/specs/2026-10-24-finance-design.md

## Global Constraints

Russian UI; worldwide currencies including USD/RUB/KZT; no fabricated production history; no runtime npm dependencies; original balances preserved; offline cached valuation with timestamps.

## Review Focus

- Missing rates must produce incomplete totals, not silently drop value.
- Retroactive balance corrections must affect later history.
- Archive must preserve past capital and permit complete exports.
- Setup, origin checks, invalid sessions and password changes must protect APIs.
- FX failure must preserve the last successful cache and back off.
